# Reference Structure Audit: DM Champ

This audit records the public information architecture and conversion patterns reviewed on 18 August 2026. It is a **structural reference only**. The Agents DX website will use original copy, layout, iconography, content hierarchy, product claims, and branded assets. No DM Champ source code, imagery, customer reviews, pricing data, customer marks, or proprietary prose will be reproduced.

| Reference journey | Relevant public pages reviewed | Agents DX interpretation |
| --- | --- | --- |
| Establish product category and convert interest | Home, Features | A distinct home page and How It Works page that explain AI-driven acquisition and automation through original content. |
| Explain agency white-label value | For Agencies, White-Label guide, Use Cases | A product-positioning narrative on the home and Features pages; no reference-specific commercial claims or comparison tables. |
| Present plans and reduce purchase friction | Pricing, Features | A dedicated pricing page with a billing control, plan cards, feature comparison, and demo-oriented CTAs. Prices and plan benefits remain editorial placeholders until approved by Agents DX. |
| Build confidence and educate prospects | Reviews, Resources | A Blog / Resources index and article-detail template. The reusable social-proof slot will remain neutral until genuine, approved testimonial and logo materials are supplied. |
| Capture sales conversations | Contact | A Book a Demo route with a contact form and non-functional calendar embed placeholder. |
| Answer objections | FAQ | A category-based FAQ that uses original, non-legal, product-appropriate answers pending Agents DX product documentation. |

## Implementation constraints

The page system is to be **visually original and materially more refined**, rather than a replication. The brand guide is the authoritative source for the Agents DX logo, colors, typography, and owned asset usage. The supplied product and pricing information will be treated as provisional until approved. The contact page calendar is intentionally a visual placeholder, not a live booking integration. Testimonials, star ratings, quotations, and client logos will not be fabricated; the component will support approved real materials when supplied.
