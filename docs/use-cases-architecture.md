# agents DX Use Cases and Footer-Page Architecture

The new page system is an original extension of the agents DX command-centre design language. It is built around practical deployment contexts instead of copied industry claims, benchmark figures, or reference-site content.

| Route | Page role | Core narrative |
| --- | --- | --- |
| `/use-cases` | Use Cases index | A selection surface for deploying an AI workforce by operating context. |
| `/use-cases/small-business` | Use-case detail | An always-available operating layer for focused teams. |
| `/use-cases/ecommerce` | Use-case detail | Useful assistance from product discovery to confident checkout. |
| `/use-cases/agencies` | Use-case detail | A repeatable client-delivery system for growing agency teams. |
| `/use-cases/enterprise` | Use-case detail | Governed AI workforce design across complex teams and systems. |
| `/use-cases/startups` | Use-case detail | Faster learning loops for founder-led momentum. |
| `/integrations` | Footer page | A system-design view of the operational connections an AI workforce can serve. |
| `/academy` | Footer page | A practical learning pathway for thoughtful AI workforce deployment. |
| `/careers` | Footer page | A forward-looking employer narrative without inventing current vacancies. |
| `/brand-guidelines` | Footer page | A public expression of the supplied agents DX visual and verbal system. |

The index and detail routes use a consistent sequence: **context → workforce mission → operating rhythm → human handoff → next action**. The new footer links will point to those routes, while Help Center continues to use the user-supplied external documentation destination.
